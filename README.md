# 💡PowerLamp

**PowerLamp** is a 3D survival game where you survive against zombies using the power of light.  
Ignite different colored lamps to gain unique abilities and survive as long as you can.


## 🧟 About the Game

The world is dark and filled with undead.  
Your only chance to survive? **Light.**

Each lamp grants a special power:
- 🟡 **Yellow Lamp** – Change your size to escape tight situations.  
- 🔴 **Red Lamp** – destroy nearby zombies.

Stay alive, keep the lamps burning, and don’t let the darkness consume you.

Built with **Godot Engine 4.5**
